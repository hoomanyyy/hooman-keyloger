# ⌨️ Educational Keylogger (Python)

> **Disclaimer مهم:** این ابزار صرفاً برای اهداف آموزشی، تست امنیت شخصی و محیط‌های آزمایشگاهی طراحی شده است.  
> استفاده غیرقانونی یا بدون اجازه روی سیستم دیگران کاملاً ممنوع است.

یک کی‌لاگر ساده که کلیدهای فشرده شده را لاگ می‌کند و به سرور می‌فرستد.

## فایل‌ها
- `client.py` → کی‌لاگر (روی سیستم هدف)
- `server.py` → سرور FastAPI برای دریافت لاگ‌ها
